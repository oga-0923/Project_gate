PROJECT GATE初期版 v0.2

ルールとカード一覧
  • デッキ20枚・初期手札3枚・ライフ5。先攻・後攻はランダム。
  • 自分のターン開始時にエネルギーが3まで回復し、山札から1枚引く（ゲーム最初の先攻1ターン目は引かない）。
  • カードはコスト分のエネルギーを払って出す。モンスターは場に最大3体。
  • 出したターンのモンスターは攻撃できない（「休」表示）。速攻持ちは例外。攻撃は1体につき1ターン1回。
  • 進化：炎の竜は、前のターンから場にいる炎の幼竜の上に重ねて出す。受けていたダメージと攻撃済みかどうかは引き継ぐ。
  • 封印の鎖を受けたモンスターは、持ち主の次のターンが終わるまで攻撃できない（「封」表示）。
  • 相手の場にモンスターがいる間は、プレイヤーを直接攻撃できない。
  • 戦闘ではお互いのATK分のダメージをHPに与え、HPが0以下で破壊。受けたダメージは聖域以外では回復しない。
  • フィールドカードは1人1枚。別のフィールドを出すと張り替わる。
  • 山札が尽きて引けないときは1ダメージ。手札が7枚のときに引いたカードは捨てられる。
  • 相手のライフを0にしたら勝ち。

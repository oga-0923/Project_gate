# PROJECT GATE

VR・MR・スマホ・PCで遊べるオリジナルのトレーディングカードゲーム。
1つのWebアプリ（`index.html`）が、遊ぶ端末に合わせて3つの形で動く。

| 遊び方 | 端末 | 開き方 |
| --- | --- | --- |
| PC版 | Windows / Mac のブラウザ | 公開URLを開く |
| スマホ版 | iPhone / Android | 公開URLを開き「ホーム画面に追加」。アプリとして全画面で起動し、一度開けば圏外でも遊べる |
| VR・MR版 | Meta Quest のブラウザ | 公開URLを開き、右上の「VRで遊ぶ」または「MRで遊ぶ」を押す。MRでは自分の部屋の机の上に卓が出る |

## VR・MRでの操作

- コントローラーの光線を向けてトリガー（手の場合は親指と人差し指でつまむ）で選ぶ
- 手札は手前、ターン終了ボタンは右手前の金色の箱、状況表示は卓の奥に浮かぶ
- 卓の高さや距離は `index.html` の `const XR = { … }` で変更できる

## ルール（Ver.2）

- デッキ20枚（固定）・初期手札3枚・ライフ5・エネルギーは毎ターン3まで回復
- モンスターは場に3体まで。出したターンは攻撃できない（速攻を除く）
- 相手の場に攻撃できるモンスターがいる間は、本体を直接攻撃できない
- 相手のライフを0にしたら勝ち
- カード一覧と詳しいルールはゲーム内の「ルール」ボタンから見られる

## ファイル構成

```
index.html               ゲーム本体（ルール・CPU・3D表示・VR/MR対応をすべて含む）
manifest.webmanifest     スマホのホーム画面アプリ用の設定
sw.js                    オフラインで遊ぶためのキャッシュ
icons/                   アプリのアイコン
legacy/project-gate-2d.html  最初に作った2D版（記録用）
CHANGELOG.md             更新履歴
```

## 公開のしかた（GitHub Pages）

1. このリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

VR・MRとホーム画面アプリは https で開いたときだけ動くので、ファイルを直接開くのではなく公開URLから遊ぶ。

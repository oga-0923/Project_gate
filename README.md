# PROJECT GATE

VR・MR・スマホ・PCで遊べるオリジナルのトレーディングカードゲーム。
1つのWebアプリ（`index.html`）が、遊ぶ端末に合わせて3つの形で動く。

| 遊び方 | 端末 | 開き方 |
| --- | --- | --- |
| PC版 | Windows / Mac のブラウザ | 公開URLを開く |
| スマホ版 | iPhone / Android | 公開URLを開き「ホーム画面に追加」。アプリとして全画面で起動し、一度開けば圏外でも遊べる |
| VR・MR版 | Meta Quest のブラウザ | 公開URLを開き、対戦中に右上の「VRで遊ぶ」「MRで遊ぶ」を押す。MRでは自分の部屋の机の上に卓が出る |

対応言語：日本語・English・简体中文・Español・한국어・Português（設定画面で切り替え）

## 画面構成

| タブ | できること |
| --- | --- |
| ホーム | 1日1パックの無料開封（毎日4:00に復活）、パックポイント、図鑑の収集率、戦績、提供割合 |
| マイカード | コレクション（所持数・未所持・カード詳細・ポイントで作成）、デッキ3つの編集、デッキコードの書き出しと読み込み |
| フレンド | プロフィール、自分のデッキコード、フレンドの登録（名前とデッキコード）、フレンドのデッキと対戦 |
| バトル | 練習、完全情報モード（お互いの山札の順番が見える）、フレンドのデッキ、ランクマッチ（準備中） |
| 設定 | 言語、演出の速さ、カメラ、最後の1枚を伏せる、VR・MRの卓の高さ、ルール、提供割合、テストモード、データ消去 |

セーブデータは端末のブラウザ（localStorage）に保存される。別の端末やブラウザとは共有されない。

## パック開封の仕掛け

確率は全員共通で、見た目や開け方では変わらない（提供割合は画面で公開）。

1. パックの個体差：角の折れ、封の向き、光の筋の位置がパックごとに違う（見た目のみ）
2. 最後の1枚を伏せて開封（設定で切り替え、見た目のみ）
3. なぞる速さで、めくれる速さが変わる（見た目のみ）
4. 時間帯でパックの色が変わる（朝・昼・夕方・夜、見た目のみ）
5. 神パックの予兆：まれに開ける前のパックがかすかに光る（1%の神パックのときだけ）

## 標準ルール

- デッキ20枚（固定）・初期手札4枚・ライフ7
- エネルギーは最初のターン2、自分のターンごとに1ずつ増える（最大4）
- 同名カードは3枚まで（カードによっては2枚まで）、★のカードは1枚まで

## ユーザー画面と開発者画面

ファイルは2種類ある。

| ファイル | 用途 | 開発者画面 |
| --- | --- | --- |
| `dev.html` | 開発・テスト用（元になるファイル） | 設定 → 画面モード で「ユーザー」「開発者」を切り替えられる |
| `index.html` | 一般公開用（GitHub Pagesのトップ） | 出ない。ユーザー画面のみ |

`index.html` は `dev.html` から自動で作るので、直接編集しない。

```
python3 tools/build_release.py
```

開発者画面でできること：全カードを使える、パックの確率を変える、次のパックの中身を指定、初期手札を指定、CPUデッキの切り替え、カード・パックポイントの追加、他のプレイヤーへのギフトコード発行。確率の変更と全カード解放は、開発者モードがオンの端末だけで効き、画面上部に赤い表示が出る。

注意：リポジトリが公開（Public）なので、`dev.html` も `https://oga-0923.github.io/Project_gate/dev.html` で開けてしまう。ギフトコードもソースを読めば偽造できる。一般公開して人が増える前に、開発者機能をサーバー側（管理者だけがログインできる仕組み）へ移す。

## ファイル構成

```
dev.html                 ゲーム本体の元ファイル（ルール・CPU・画面・3D表示・VR/MR・多言語・開発者画面）
index.html               一般公開用（tools/build_release.py で dev.html から自動生成）
tools/build_release.py   一般公開用を作るスクリプト
manifest.webmanifest     スマホのホーム画面アプリ用の設定
sw.js                    オフラインで遊ぶためのキャッシュ
icons/                   アプリのアイコン
legacy/project-gate-2d.html  最初に作った2D版（記録用）
CHANGELOG.md             更新履歴
```

`dev.html` の主な調整箇所（変更したら `python3 tools/build_release.py` で index.html を作り直す）：`const CONFIG`（ルールの数値・パック枚数・神パック確率など）、`const RARITY`（提供割合）、`const CARDS`（カードの能力）、`const STARTER`（初期デッキ）、`const NAME` / `const MOTIF` / `const STR`（多言語の文言）、`const XR`（VR・MRの卓の位置）。

## 公開のしかた（GitHub Pages）

1. このリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://oga-0923.github.io/Project_gate/` で遊べる

VR・MRとホーム画面アプリは https で開いたときだけ動くので、ファイルを直接開くのではなく公開URLから遊ぶ。
